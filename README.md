# Кладовка — карта конкурентов Приморья

Интерактивная карта для сравнения потребительских сценариев, сетей, парковок и расписаний магазинов.

## Как пользоваться

- Слева магазины сгруппированы по названию сети. Нажмите на сеть: все её точки в текущих фильтрах появятся на карте, справа откроется выбор филиала. Кнопка «Все точки на карте» снимает фильтры и показывает всю сеть.
- Общие названия вроде «Минимаркет» не объединяются в одну сеть. Для остальных неподтверждённых совпадений названий показана пометка «Группа по названию». Это не подтверждение единого владельца.
- Кнопка «Зоны 500 м» включает окружности вокруг видимых магазинов. Нажмите любое место на карте или «Сценарии в 500 м» в карточке: сводка покажет конкурентов и сценарии внутри выбранного радиуса. Расстояние географическое по прямой; это не 10 минут пешком или на машине.
- По умолчанию анализ зоны учитывает все магазины из таблицы, независимо от выбранной сети и фильтров карты. Можно включить «Учитывать фильтры карты». При анализе вокруг магазина сама точка в центре исключается.
- В сводке зоны раздельно показаны сведения по каталогам/рубрикам и гипотезы. Ноль означает отсутствие точек в выгрузке, а не доказанное отсутствие конкурентов на рынке. Один магазин может участвовать в нескольких сценариях.
- Фильтр расписания: «Открыто сейчас», 24/7, сегодня в 21:00 или выбранный день и время. Время — Владивосток (UTC+10). Ночные интервалы и перерывы учитываются. Праздники и индивидуальные оговорки не проверяются в реальном времени; «о» и отсутствующие сведения не трактуются как выходной.

## Источник и обновление

[Google-таблица проекта](https://docs.google.com/spreadsheets/d/1bTyx8eIPhnzij_5aPb3AVSiPx8Ky_nJpjnsYHM2aOpc/edit#gid=1117777643), лист «Конкуренты приморье».

Данные читаются при открытии, по кнопке обновления и каждые 5 минут, пока страница открыта и видима. API-ключа нет. Используется существующий доступ по ссылке; закрытие доступа остановит обновления. Заголовки колонок A:AV должны сохраняться. Новые строки подхватываются автоматически, но сценарии и реквизиты новых магазинов нужно заполнять в таблице.

## Рекомендации для поиска помещения

Кнопка «Рекомендации» показывает до 10 приоритетных поисковых зон. Это альтернативные центры поиска, а не предложения свободных помещений. География центров ограничена 339 проверенными кругами в 29 населённых пунктах; 180 центров расположены во Владивостоке. Полный перебор каждого адреса не выполнялся. Центры выбраны в населённых ячейках WorldPop 1 км, дополнены адресами магазинов и ориентирами микрорайонов; плотные зоны представлены чаще. Координата существующего магазина служит только ориентиром зоны и не означает доступности его помещения.

Для каждого центра отдельно получена сумма модельного населения в геодезическом круге 500 м через официальный WorldPop API v2: `year=2025`, `resolution=100m`, источник ответа `worldpop_R2025A_2025_100m`. Круг аппроксимирован 72 отрезками. Население не рассчитано делением численности микрорайона на площадь. Показ округлён до сотен, расчёт использует исходное значение API. Это модель жителей, не перепись и не дневной поток; новостройки могут отражаться неполно. [WorldPop Global2](https://www.worldpop.org/blog/worldpop-global2-global-high-resolution-population-estimates-for-2015-2030/), [документация API](https://api.worldpop.org/v2/docs), CC BY 4.0. Конкретный вариант constrained / UN adjustment API в своём ответе не указывает; точный источник ответа и URL результата сохранены у каждого центра. Слой 1 км служит только для выбора центров и не используется для оценки населения в 500 м.

Население всегда относится к 500 м. Радиус конкуренции выбирается отдельно: 250 / 500 / 750 / 1000 / 1500 м. Учитываются текущие фильтры карты, включая выбранную сеть, расписание, парковку и сценарий. Основание оценки показывается в карточке и используется для разделения сведений и гипотез, но исключено из фильтров. Географические фильтры также ограничивают выбор центров. Для каждой зоны показан контроль по всем активным конкурентам без фильтров: исключённые фильтрами магазины не объявляются отсутствующими на рынке. Статус «Нет» в Google-таблице исключает магазин из обоих расчётов.

Целевые сценарии — уникальные значения столбца A листа «Ассортимент»; при выборе сценария в фильтре оценивается только он. Лист читается при включении рекомендаций и каждые 5 минут; при сбое используется снимок 26 сценариев от 25.10.2026. Сценарии по каталогам / рубрикам, только гипотезы и отсутствие записи различаются. Гипотезы и неизвестное основание не дают баллов за свободный сценарий. «Не найден» означает отсутствие в этой выгрузке, а не доказанный дефицит на рынке. Каталог сети или рубрика не подтверждают наличие товара в конкретном филиале.

Начальные рабочие допущения, доступные для изменения:

`балл = max(0, min(100, 60 × min(население500 / 10000, 1) + 40 × (сценарии без найденной конкуренции / целевые сценарии) − штраф этажа))`.

Первый этаж — 0 штрафа; выше первого — 15 баллов. При неизвестном этаже явно предполагается первый. Этаж можно задавать для всех зон и отдельно для конкретной. Парковка имеет отдельное допущение (неизвестна / предполагаем доступную / предполагаем отсутствие) и никогда не меняет балл. Ближайшая нанесённая парковка показана как ориентир; право пользования для будущего магазина не подтверждено. Допущения хранятся в этом браузере и не записываются в Google-таблицу. Кнопка «Сбросить допущения зон» очищает индивидуальные значения: это позволяет вернуть зону, вышедшую из топ-10 после штрафа за этаж.

Порог населения по умолчанию — 1000 жителей; целевой уровень для полного балла населения — 10000. Веса, порог и штраф — параметры гипотезы, не статистически обученная модель. При равном балле выбирается большее население, затем стабильный ID. Между центрами топ-10 не менее 500 м, но круги жителей могут пересекаться: их нельзя складывать для оценки сети. При недоступном населении точка не ранжируется, неизвестное не заменяется нулём.

CSV рекомендаций содержит баллы и компоненты, сценарии, текущие фильтры, контроль полной базы, координаты, допущения и ссылку на расчёт населения. Рекомендации пересчитываются при изменении фильтров и обновлении конкурентов из таблицы. Само население 2025 и набор проверенных центров — опубликованный снимок; добавление нового города или обновление модели населения требует пересчёта и публикации.

Оценка не измеряет продажи или рентабельность. Перед выбором помещения нужны полевой аудит соседей, проверка свободного помещения, аренды, входа, этажа, пеших подходов, подъезда и возможности парковки. 500 м по прямой не равны 10 минутам пути.

## Окна поверх карты

Блок обновления данных и легенда закрываются крестиком независимо друг от друга. Вернуть их можно кнопками «Данные» сверху слева и «Легенда» снизу слева. Выбор сохраняется в этом браузере после перезагрузки. Открытие и закрытие карточки магазина, обновление Google-таблицы и переключение слоёв не отменяют скрытие. Чтение таблицы продолжает работать, даже когда блок состояния закрыт.

## Ручная проверка места и цвета сценариев

«Проверить место» включает курсор с меткой. Следующий щелчок в любом месте карты ставит самостоятельную гипотезу H1, H2…; Escape отменяет постановку. Слой микрорайонов и маркеры магазинов не перехватывают щелчок в этом режиме. В карточке — собственный круг 500 м, выбранный радиус конкуренции, текущие фильтры и контроль полной базы. Население рассчитывается для координаты через официальный WorldPop API v2 (2025, 100 м), без подстановки ближайшей автоматической рекомендации. При сбое или лимите API население остаётся неизвестным и общий балл не рассчитывается. Можно повторить запрос.

Точки сохраняются в localStorage этого браузера и переживают перезагрузку. Это не общая база для всех посетителей и не запись в Google-таблицу. «Мои точки» открывает список; можно менять название, этаж и парковку, скачать CSV, удалить точку и вернуть последнее удаление до перезагрузки. Этаж выше первого получает штраф по настройкам рекомендаций; парковка на балл не влияет. Точки гипотез не включаются в конкурентов.

Цвет магазина определяется полным множеством сценариев, независимо от сети и формата; порядок, повторы, регистр и ё/е нормализуются. Алгоритм стабилен между фильтрами и обновлениями. У текущих 161 наборов разные значения цвета, но визуально близкие оттенки возможны; точный состав доступен через «Все наборы на карте» и в карточке. Одноцветный кластер содержит один набор; разноцветный ободок показывает доли магазинов с разными наборами. Легенда относится к магазинам с координатами в текущей выборке. Оценочные категории и гипотезы ассортимента сохраняются в карточках, отдельный фильтр «Основание оценки» убран.

Контур «Центра» исправлен по замечанию пользователя: часть южного берега Золотого Рога в Первомайском районе перенесена в условный «Чуркин». Для отсечения использован опубликованный контур Первомайского района 2ГИС, ссылка сохранена в метаданных. Объединение двух зон сохранено; население каждого изменённого контура заново запрошено у WorldPop. Условный статус остаётся. Микрорайон магазина и поисковой зоны определяется текущей геометрией, поэтому старое название в снимке или столбце таблицы не возвращает южный берег в «Центр».

## Микрорайоны

Слой содержит 42 контура: 19 опубликованных контуров 2ГИС / OpenStreetMap и 23 условные рабочие зоны. Условные зоны отмечены в названии и пунктиром. Это воспроизводимая разбивка для первичного анализа, а не утверждённые границы привычных микрорайонов. Рабочие зоны построены по ближайшему адресу-ориентиру (ячейки Вороного), обрезаны городским контуром OSM, радиусом 3 км и опубликованными контурами. Ориентиры и метод указаны в файле `neighbourhoods.js` и карточке района. Названия и ориентиры следует уточнить с местным знанием перед выбором помещения.

Население — сумма WorldPop Global2 R2025A за 2025 год по сетке 100 м внутри каждого показанного контура, округлённая до сотен; <100 означает малое положительное значение модели. Это модельная оценка, не перепись и не проектная вместимость застройки. Для условных зон она относится именно к рабочему контуру. Исходные данные могут не отражать заселение новостроек. Контуры справочников могут пересекаться; численность и магазины разных контуров нельзя складывать без устранения пересечений. Источники и результаты API доступны в карточках.

В листе «Конкуренты приморье» столбец B «Конкурент / нет»: «Нет» скрывает точку из всех списков, фильтров, маркеров, CSV и анализа 500 м. «Конкурент» возвращает её при следующем чтении таблицы. Пустой статус новой строки считается конкурентом. Обновление — при открытии, по кнопке и каждые 5 минут в открытой вкладке. Пока Google недоступен, может отображаться прежний статус из последнего снимка; текущий источник и время видны на карте.

## Выручка и адрес

У шести адресов совпали название юрлица и здание, а 2ГИС показывает один филиал: Вис-магнит, Чистота 21 век-Прим, Евровосток, Три товарища, Владмаркет, Паровозик. Выручка ГИР БО за 2025 добавлена как ориентир связанного юрлица; совпадение не подтверждает единственный канал продаж и выручку отдельного магазина. Для сетей, ИП и неподтверждённых совпадений выручка по адресам не распределяется. Рентабельность места требует данных о расходах, аренде и выручке самой точки. Колонки с общей выручкой/прибылью юрлица сохраняются отдельно и не суммируются по филиалам.

В этой версии добавлены 649 деловых контактов, 42 поля этажа/помещения и три имени ИП из исходных публичных карточек. Служебные ссылки сервиса чеков исключены из сайтов магазинов. Пробелы, не подтверждённые источниками, остаются неизвестными.

При сбое Google показывается последний кэш браузера или встроенный снимок от 25.10.2026: 912 магазинов, 908 с координатами. Финансовые показатели относятся ко всему юридическому лицу и повторяются у его филиалов; не суммировать по строкам магазинов.

## Категории, задачи и сценарии

25–26.10.2026 разметка перестроена по единому справочнику из 504 категорий листа «Ассортимент»: 18 сценариев, названных действиями покупателя. Категория — конкретная товарная группа, задача — действие, сценарий — цель. Например: «Губки для посуды» → «Вымыть посуду вручную» → «Убрать дом и вынести мусор». Маркеры и канцелярские ножницы относятся к учёбе/работе, столовые приборы — к сервировке. Товарные названия, финансовые данные, координаты и пользовательские флаги ассортимента сохранены.

В «Конкуренты приморье» добавлен F «Предполагаемые категории». G/H пересобраны из F по справочнику; I/J содержат основания и ссылки. Рубрика «Хозтовары» не расширяет автоматически ассортимент специализированного магазина до уборки при наличии более точных рубрик. Каталоги сетей и рубрики подтверждают направление; детализация категорий предполагаемая, наличие SKU в филиале не проверялось. У 450 продуктовых точек без non-food источника оставлена явно обозначенная гипотеза по формату. Это не полная инвентаризация и не доказательство отсутствия товаров вне списка.

Статус «Нет» установлен только для «Азия-Восток», Запорожская, 77, офис 636, 6 этаж: в 2ГИС это таможенно-логистическая компания, а не магазин у дома. Запись сохранена; при подтверждении розницы статус можно вернуть. Остальные оптовики и продуктовые магазины не исключены из-за недостатка сведений.

Сайт читает категории из F и словарь A:R с листа «Ассортимент». Сценарии и задачи в карточке рассчитываются из категорий при каждом обновлении. «Под вопросом» и «да» в ассортименте учитываются; «нет» исключается. Неизвестные названия категорий показываются в карточке с предупреждением, сценарии для них не придумываются. Добавлены фильтр товарной категории, поиск по категориям, расшифровка «категория → задача → сценарий» и категория в CSV. Фильтр категорий также сужает набор сценариев в рекомендациях.

Пересечение хотя бы по одной выбранной категории означает конкуренцию в части сценария, а не полное покрытие всех его задач. Сценарный показатель рекомендаций — поисковая гипотеза, не полнота ассортимента и не прогноз рентабельности. Основная таблица — A:AW; отдельный реестр юрлиц справа автоматически сдвинут в AY:BT и не смешан со строками магазинов.

## Размещение

Статический сайт, без сервера, сборки и секретных ключей. GitHub Pages: ветка `main`, папка `/ (root)`. Файл `.nojekyll` отключает обработку Jekyll. Для локальной проверки подходит любой статический HTTP-сервер.

Библиотеки Leaflet и Leaflet.markercluster включены в репозиторий; их лицензии — в `THIRD_PARTY_LICENSES.txt`. Картографическая подложка — OpenStreetMap; для неё нужен интернет.
